# git-ploy

Tiny autoupdater service: it runs `git pull` in this repository and executes your deploy script when changes arrive.

## Install

```sh
curl -sSL https://raw.githubusercontent.com/golem-vanity-market/git-ploy/refs/heads/main/install-service.py | sudo python3
```

## Uninstall

```sh
curl -sSL https://raw.githubusercontent.com/golem-vanity-market/git-ploy/refs/heads/main/uninstall-service.py | sudo python3
```
